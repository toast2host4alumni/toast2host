# Toast2Host Backend (Strapi v5, TypeScript)

• Strapi v5 configured for TypeScript.
• GraphQL plugin enabled (see `config/plugins.ts`).
• Add content-types under `src/api/**/content-types/**/schema.json`.
• Custom GraphQL resolvers under `src/extensions/graphql/resolvers/*.ts`.

See feature docs in `specs/001-alumni-connect-mvp/`.
